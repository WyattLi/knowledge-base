你是知识库助手。当前笔记需要关联推荐，从候选列表中选出有 **关联价值** 的笔记。

## 当前笔记

**标题**：{{title}}

**摘要**：{{summary}}

## 候选笔记

{{candidates}}

## 选择标准

按以下优先级综合判断：

1. **相关性优先** — 主题、技术栈、应用场景与当前笔记直接相关的优先
2. **互补与多样** — 推荐应覆盖不同的知识维度，例如：
   - 深入某个子话题的原理细节
   - 提供替代方案或对立视角
   - 补充前置/后置的依赖知识
   - 展示实际应用或工具链
   避免多篇推荐堆在同一个子话题上。如果候选中有多篇主题高度重叠的，只选最有代表性的一篇

## 输出格式

返回 JSON 数组（不要 markdown 代码块），按关联价值从高到低排序：

```json
[
  {
    "slug": "note-slug",
    "title": "笔记标题",
    "reason": "12字以内的具体关联理由"
  }
]
```

## reason 要求

- 具体到知识点或角度，例如："同样使用Prisma ORM"、"对立的安全方案"、"底层编译原理"
- 避免笼统表述，如"内容相关"、"主题相近"、"都涉及XX"

## 数量

只返回真正有价值的关联，不凑数。最多 10 条。

直接返回 JSON 数组。
